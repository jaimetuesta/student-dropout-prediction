# Predicting University Student Dropout and Academic Performance with Machine Learning

**Author:** Jaime Tuesta de Simón (individual project)
**Context:** Coursework for *Aprendizaje Automático* (Machine Learning), Universidad Pontificia Comillas (ICAI), 2026.
**Language:** notebooks and report are in Spanish; this README is in English.

## Overview

Analysis of student retention and academic performance using the *Predict Students' Dropout and Academic Success* dataset (UCI Machine Learning Repository). Three problems are addressed:

- **Classification** of the final academic outcome: *graduado* (graduate) / *abandono* (dropout) / *matriculado* (still enrolled).
- **Regression** of the average grade of the second semester (`nota_media_2sem`), using only background and first-semester variables.
- **Unsupervised learning** (PCA + K-Means) to look for student profiles.

The full write-up is in [`report/`](report/JaimeTuesta_Informe_Proyecto_ML.pdf) (Spanish).

## Dataset

[Predict Students' Dropout and Academic Success](https://doi.org/10.24432/C5MC89) — Realinho, Vieira Martins, Machado and Baptista (2021), UCI Machine Learning Repository, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

4,424 students, 37 columns: 36 predictors (19 numeric, 17 categorical; academic, socioeconomic and macroeconomic) plus the target `objetivo`. There are no missing values or duplicates.

`rendimiento_estudiantes.csv` is an adapted copy of the original data: column names and category labels are in Spanish and the separator is `;`. Original data and paper: see the DOI above and Realinho et al. (2022), *Data* 7(11), 146, https://doi.org/10.3390/data7110146.

## How to run

Reference environment: Python 3.12.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cd notebooks
jupyter notebook
```

Run the notebooks **in order, from `notebooks/`** (paths are relative): `01` → `02` → `03` → `04` → `05`. Notebook 02 must run before 03 and 04, which load its preprocessors. All random seeds are fixed (`random_state=0`).

The outputs stored in the notebooks were produced with Python 3.12.4 and the numpy, pandas and scikit-learn versions pinned in `requirements.txt`. Other library versions can give slightly different numbers (in particular for the random forest classifier and for the unregularised linear regression, see below).

## Results

Held-out test set (20%, 885 students), single 80/20 split with `random_state=0` (stratified for classification).

| Task | Best model | Main metric |
|---|---|---|
| Classification | Logistic Regression (balanced class weights) | macro F1 = 0.72 (accuracy 0.76). Random Forest 0.68, Gradient Boosting 0.69 |
| Regression | Random Forest | R² = 0.783, RMSE = 2.46, MAE = 1.28. Ridge R² = 0.765, Lasso R² = 0.697 |
| Clustering | K-Means | silhouette = 0.490 for k = 2 (0.367 for k = 3) |

What the analysis shows:

- **Classification.** Academic performance dominates. In all three models the most important variable is the number of subjects passed in the second semester (`asignaturas_2sem_aprobadas`), followed by first-semester passed subjects and the average grades. Since second-semester variables are included, this model describes the final outcome from first-year performance; it is **not** an early-warning system. The *matriculado* class is the hardest one (F1 between 0.40 and 0.53).
- **Regression.** Second-semester variables are excluded to avoid leakage. Lasso keeps only 2 of 240 features (`nota_media_1sem` and `asignaturas_1sem_aprobadas`), and the random forest ranks the same two first. The unregularised linear regression is numerically unstable in the reference run (R² ≈ −9·10¹⁷), which goes together with a collinear (rank-deficient) one-hot design matrix; with other library versions the same model can give reasonable values, so it is kept only as a baseline.
- **Clustering.** With k = 3, one cluster (842 students) has almost no passed subjects and 82% dropout, covering about half of all dropouts. The other two clusters have a similar outcome mix and differ mainly in age and validated subjects. The clustering uses variables from both semesters.

## Limitations

- Single train/test split; no cross-validation and no hyperparameter tuning (default values, `alpha = 1` for Ridge/Lasso). Differences between models of similar performance should not be over-interpreted.
- The *matriculado* class groups students whose final outcome is still unknown.
- About 20% of the regression target is exactly 0 (students who passed no subjects in the second semester), which explains the long error tails.
- Data from a single institution; the associations found are not causal.
